### AI × Infrastructure

The interesting problem isn't whether a model can write Terraform. It's building the
harness — context, tools, permissions, verification — so what it produces is safe to
apply. That's platform engineering, pointed at a new kind of user.

Agent output goes through the same bar as human output: review, tests, CI, and
deterministic hooks for the rules that must hold every time. Autonomy where it's cheap
to be wrong, gates where it isn't.

### How I work

- **Boring is the goal.** The best infrastructure outcome is that nobody thinks about it. Clever is a cost you pay every time someone new joins or something breaks at 3am.
- **Verified, not asserted.** "It's deployed" isn't the same as "it works". Whatever I hand over has been run, checked, and shown to do the thing — including the failure paths.
- **Your team keeps it.** Work that only I can maintain isn't finished. Conventions get written down, decisions get their reasons attached, and handover is part of the job.
